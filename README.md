# GEP II Project (formerly NAGE Inventory II)

A set of standalone Python tools dedicated to the energetic analysis of observational astronomical data, focusing on the characterization of galactic halos and the Circumgalactic Medium (CGM).

Manuscript Reference: [Zenodo DOI](https://doi.org/10.5281/zenodo.22011957)

Website Reference: [andreabrussi.it](https://andreabrussi.it)  
Contact: info@andreabrussi.it  - [ORCID](https://orcid.org/0009-0000-3924-1563)

---

## Zip Content

The package includes the following computation and analysis scripts:

*   Brussi_2026_GEP_II_Halo_magnetic_energy_file1.py – Halo magnetic energy analysis.
*   Brussi_2026_GEP_II_CGM_thermal_energy_file2.py – Circumgalactic Medium (CGM) thermal energy computation.
*   Brussi_2026_GEP_II_Ordered_rotational_K_energy_file3.py – Ordered rotational kinetic energy analysis.
*   Brussi_2026_GEP_II_Global_Cluster_K_energy_file4.py – Global cluster kinetic energy analysis.
*   Brussi_2026_GEP_II_Velocity_dispersion_K_energy_file5.py – Velocity dispersion kinetic energy study.
*   Brussi_2026_GEP_II_Total_energy_profile_file6.py – Total energy profile computation and analysis of $P(r)$ pressure functions.

---

## Usage and Data Entry

All scripts are standalone applications designed to be executed directly from the terminal (command-line interface).

1. Open your terminal in the directory where you extracted the ZIP archive.
2. Run the desired script using Python (e.g., python Brussi_2026_GEP_II_Halo_magnetic_energy_file1.py).
3. Follow the minimal interactive on-screen prompts to input your data (data entry).
